1. What is RTL Design, Simulation and Testbench?

RTL Design

RTL stands for Register Transfer Level.

RTL is a method of describing the operation and data flow of a digital circuit using a Hardware Description Language (HDL), such as Verilog.

RTL design describes:

- Data flow between registers
- Combinational logic
- Sequential logic
- Control signals
- Inputs and outputs

The RTL description can later be synthesized into hardware components such as logic gates, multiplexers and flip-flops.

Simulation

Simulation is used to verify the behaviour of a digital design before implementing it on actual hardware.

During simulation, input signals are applied to the design and the resulting output signals are observed.

Simulation helps identify:

- Logic errors
- Incorrect outputs
- Incorrect signal connections
- Unexpected circuit behaviour

---

Testbench

A testbench is a verification environment used to test the functionality of a Verilog design.

A testbench provides input signals to the Design Under Test (DUT) and observes the corresponding outputs.

The main functions of a testbench are:

1. Generate input signals
2. Apply different test cases
3. Observe output signals
4. Verify expected behaviour
5. Generate waveform data

2. Getting Started with Verilog

Introduction to Verilog HDL

Verilog HDL is a Hardware Description Language used to model and design digital electronic systems.

Unlike conventional programming languages, Verilog describes hardware behaviour and structure.

A Verilog design generally consists of modules, input ports, output ports and logic used to describe the required circuit.

Important Concepts

Module

A module represents a basic building block of a digital circuit.

Input

Input ports receive signals from external circuits or testbenches.

Output

Output ports provide the result generated by the circuit.

Combinational Logic

The output depends only on the current input values.

Examples include:

- Multiplexers
- Adders
- Encoders
- Decoders

Sequential Logic

The output depends on present inputs as well as previous states.

Examples include:

- Flip-flops
- Counters
- Registers

3. Lab: Simulating a 2-to-1 Multiplexer

Aim

To design and simulate a 2-to-1 Multiplexer using Verilog HDL and verify its functionality using a testbench and waveform analysis.

2-to-1 Multiplexer

A 2-to-1 multiplexer is a combinational digital circuit that selects one of two input signals and sends the selected signal to the output.

It consists of:

- Two data inputs: I0 and I1
- One select input: S
- One output: Y

Truth Table

Select S| Output Y
0| I0
1| I1


---

4. Verilog Design Analysis

The multiplexer is described using Verilog HDL as a combinational circuit.

The design contains:

- Input ports
- Output port
- Select signal
- Combinational selection logic

The select signal determines which input reaches the output.

Working Principle

S = 0 → Y follows I0

S = 1 → Y follows I1

This demonstrates how a simple RTL description can represent the functionality of an actual hardware multiplexer.

6. Simulation and Waveform Analysis

After completing the RTL design and testbench, the design was compiled and simulated.

The simulation generates signal values with respect to time.

The important signals observed are:

- I0
- I1
- S
- Y

The waveform allows us to visually verify whether the output follows the selected input.

Waveform Observation

When S = 0, the output follows I0.

When S = 1, the output follows I1.

Therefore, the waveform confirms the correct operation of the multiplexer.
