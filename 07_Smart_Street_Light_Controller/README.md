# Smart Street Light Controller Using Verilog RTL

## 1. Project Overview

The Smart Street Light Controller is a digital design project developed as part of the RTL Design Workshop. It demonstrates the design and implementation of street light control logic using Verilog HDL.

The project focuses on delayed switching and fault detection and uses the OpenLane RTL-to-GDSII flow for physical implementation.

## 2. Objectives

- Design a street light controller using Verilog HDL.
- Implement delayed switching and fault-detection logic.
- Verify the RTL design through simulation.
- Perform logic synthesis and physical design.
- Analyze timing and physical verification reports.
- Generate the final GDSII layout.

## 3. Tools and Technologies

- Verilog HDL
- Icarus Verilog
- Yosys
- OpenLane
- SkyWater SKY130A PDK
- Standard Cell Library: `sky130_fd_sc_hd`
- Magic layout and verification tools

## 4. Design Methodology

The project follows the RTL-to-GDSII implementation flow:

1. RTL design
2. Functional simulation
3. Logic synthesis
4. Floorplanning
5. Standard-cell placement
6. Routing
7. Timing analysis
8. Physical verification
9. GDSII layout generation

## 5. Technology Configuration

- **PDK:** SKY130A
- **Standard Cell Library:** `sky130_fd_sc_hd`
